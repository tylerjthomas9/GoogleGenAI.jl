GoogleGenAI.GoogleProvider — Type
GoogleProvider(; api_key="", base_url="https://generativelanguage.googleapis.com", api_version="v1beta", retry_options=nothing, http_options=(;))

A configuration object used to set up and authenticate requests to the Google Generative Language API.

Fields

  • api_key::String: Your Google API key. If not provided, the constructor will automatically check for GOOGLE_API_KEY or GEMINI_API_KEY environment variables (with GOOGLE_API_KEY taking precedence if both are set).
  • base_url::String: The base URL for the Google Generative Language API. The default is set to "https://generativelanguage.googleapis.com".
  • api_version::String: The version of the API you wish to access. The default is set to "v1beta".
  • retry_options::Union{Nothing,RetryOptions}: Retry policy for failed requests; see RetryOptions. nothing disables retries.
  • http_options::NamedTuple: Default keyword arguments for every HTTP.request call, e.g. (readtimeout=60,). Per-call http_options/http_kwargs override these.

GoogleGenAI.RetryOptions — Type
RetryOptions(; attempts=5, initial_delay=1.0, max_delay=60.0, exp_base=2.0, jitter=1.0, http_status_codes=[408, 429, 500, 502, 503, 504])

Retry policy for failed API requests. Pass it to GoogleProvider as retry_options; requests are not retried without it.

A request is tried at most attempts times, and only retried when the response status is in http_status_codes. Before retry n the client waits initial_delay * exp_base^(n - 1) + rand() * jitter seconds, or, when the server says how long to wait (a Retry-After header or a RetryInfo error detail), that long; either way at most max_delay. Streaming requests are only retried before the first chunk.

GoogleGenAI.SafetySetting — Type
SafetySetting

Fields

  • category::String: The type of harmful content to filter. Must be one of:
    • "HARM_CATEGORY_HARASSMENT"
    • "HARM_CATEGORY_HATE_SPEECH"
    • "HARM_CATEGORY_SEXUALLY_EXPLICIT"
    • "HARM_CATEGORY_DANGEROUS_CONTENT"
    • "HARM_CATEGORY_CIVIC_INTEGRITY"
  • threshold::String: The sensitivity level for blocking content. Must be one of:
    • "BLOCK_NONE": Never block.
    • "BLOCK_ONLY_HIGH": Block only content with a high likelihood of harm.
    • "BLOCK_MEDIUM_AND_ABOVE": Block when medium or high probability of unsafe content
    • "BLOCK_LOW_AND_ABOVE": Block when low, medium or high probability of unsafe content
    • "HARM_BLOCK_THRESHOLD_UNSPECIFIED": Threshold is unspecified, block using default threshold
    • "OFF": Turn the safety filter off.

GoogleGenAI.ThinkingConfig — Type
ThinkingConfig(; include_thoughts=nothing, thinking_budget=nothing, thinking_level=nothing)

Controls the model's internal thinking. Unset fields are left to the model's default.

See https://ai.google.dev/gemini-api/docs/thinking.

Fields

  • include_thoughts::Union{Nothing,Bool}: Return thought summaries in the response.
  • thinking_budget::Union{Nothing,Int}: Thinking budget in tokens (-1 for dynamic, 0 to turn thinking off where the model allows it). Used by Gemini 2.5 models.
  • thinking_level::Union{Nothing,String}: One of "minimal", "low", "medium", "high" or "xhigh" (case-insensitive). Used by Gemini 3 models.

Set at most one of thinking_budget and thinking_level.

GoogleGenAI.GenerateContentConfig — Type
GenerateContentConfig

Optional model configuration parameters.

Fields

  • http_options=(;): Keyword arguments passed to HTTP.request for this call, overriding the provider's http_options. See https://juliaweb.github.io/HTTP.jl/stable/reference/#HTTP.request.
  • system_instruction: Instructions for the model: a string, a vector of strings and parts, or a content dict with parts.
  • temperature::Union{Nothing,Float64}: Controls the degree of randomness in token selection.
  • top_p::Union{Nothing,Float64}: Selects tokens from most to least probable until the sum of their probabilities equals this value.
  • top_k::Union{Nothing,Float64}: Samples the top_k tokens with the highest probabilities at each step.
  • candidate_count::Union{Nothing,Int}: Number of response variations to return.
  • max_output_tokens::Union{Nothing,Int}: Maximum number of tokens that can be generated.
  • stop_sequences::Union{Nothing,Vector{String}}: List of strings that tell the model to stop generating text.
  • response_logprobs::Union{Nothing,Bool}: Whether to return the log probabilities of chosen tokens.
  • logprobs::Union{Nothing,Int}: Number of top candidate tokens to return log probabilities for.
  • presence_penalty::Union{Nothing,Float64}: Penalizes tokens that already appear, increasing diversity.
  • frequency_penalty::Union{Nothing,Float64}: Penalizes tokens that appear repeatedly, increasing diversity.
  • seed::Union{Nothing,Int}: Fixed seed for reproducibility; otherwise, a random number is used.
  • response_mime_type::Union{Nothing,String}: Output response media type.
  • response_schema::Union{Nothing,AbstractDict}: Schema (OpenAPI subset) that the generated candidate text must adhere to.
  • response_json_schema::Union{Nothing,AbstractDict}: A JSON Schema the output must follow. Use instead of response_schema.
  • safety_settings::Union{Nothing,Vector{SafetySetting}}: Safety settings to block unsafe content.
  • tools::Union{Nothing,Vector{Any}}: Tools the model may use: tool dicts (see google_search_tool, url_context_tool, code_execution_tool, google_maps_tool, file_search_tool, computer_use_tool), FunctionDeclarations, or Julia functions (declared by name with no parameters).
  • function_declarations::Union{Nothing,Vector{FunctionDeclaration}}: Declarations of functions that the model can call.
  • tool_config::Union{Nothing,ToolConfig} = nothing: Associates model output to a specific function call.
  • labels::Union{Nothing,Dict{String,String}}: User-defined metadata labels.
  • cached_content::Union{Nothing,String}: Resource name of a context cache.
  • response_modalities::Union{Nothing,Vector{String}}: Requested modalities of the response.
  • media_resolution::Union{Nothing,String}: Specified media resolution.
  • speech_config::Union{Nothing,AbstractDict}: Speech generation configuration.
  • thinking_config::Union{Nothing,ThinkingConfig}: Thinking features configuration.
  • image_config::Union{Nothing,AbstractDict}: Image generation options, e.g. Dict(:aspectRatio => "16:9", :imageSize => "2K").
  • service_tier::Union{Nothing,String}: Processing tier: "standard", "flex" or "priority".

GoogleGenAI.generate_content — Function
generate_content([provider | api_key], model_name, contents; image_path="", images=NamedTuple[], config=GenerateContentConfig()) -> NamedTuple

Generate a response from the model.

Arguments

  • provider::AbstractGoogleProvider or api_key::String: Omit both to read the key from GOOGLE_API_KEY or GEMINI_API_KEY.
  • model_name::String: The model to use, e.g. "gemini-3.5-flash".
  • contents: A prompt string; a vector of parts for one user turn (strings, files returned by upload_file, media NamedTuples with path, data or uri plus mime_type, or raw part dicts); or a conversation, i.e. a vector of content dicts with role and parts.

Keyword Arguments

  • image_path::String: Path of an image to attach to the last user turn.
  • images::AbstractVector: Media NamedTuples (path, or data with mime_type) to attach to the last user turn.
  • config::GenerateContentConfig: Configuration for the request.

Returns

A named tuple with:

  • text: The answer text (thought summaries excluded).
  • images: Generated images as (data, mime_type) tuples.
  • function_calls: FunctionCalls requested by the model, or nothing.
  • finish_reason, usage_metadata, safety_ratings, candidates: As reported by the API.
  • response_status: The HTTP status code.

GoogleGenAI.generate_content_stream — Function
generate_content_stream([provider | api_key], model_name, contents; image_path="", images=NamedTuple[], config=GenerateContentConfig()) -> Channel

Generate a response as a stream, yielding partial results as they arrive. Arguments are the same as for generate_content.

Returns

  • Channel: A channel that yields one named tuple per streamed chunk, with fields:

    • text::String: The text in this chunk.
    • full_text::String: All text received so far.
    • function_calls: The function calls received so far, or nothing.
    • images: Images in this chunk.
    • finish_reason: Why generation stopped; nothing until the last chunk.
    • usage_metadata: Token counts reported with this chunk.
    • candidates, safety_ratings, status: The raw candidates, safety ratings and HTTP status.

    If the request fails, including an error sent partway through the stream, the last item instead has an error field holding the exception (usually a GeminiAPIError), with text="" and finish_reason="ERROR".

Create a persistent chat session. Equivalent to client.chats.create(...) in Python.

Arguments

  • api_key::String: Your Google API key as a string.
  • model::String: The model to use for the chat.

Keyword Arguments

  • config::GenerateContentConfig: Configuration applied to every message.
  • functions::Dict{String, <:Function}: Implementations, by name, of the functions declared in config; when non-empty, function calls returned by the model are executed automatically and their results fed back until the model produces a final answer.

GoogleGenAI.create_batch_job — Function
create_batch_job(
    api_thing, model_name::String;
    requests::Union{Nothing,Vector{BatchRequest}}=nothing,
    input_file::Union{Nothing,String}=nothing,
    display_name::String="",
    http_kwargs...,
) -> JSON3.Object

Creates an asynchronous batch generation job (50% cost of interactive calls, target turnaround time of 24 hours). Pass either a vector of BatchRequest (inline requests; total request size must stay under 20MB), or the name of a JSONL file previously uploaded through the File API as input_file. Each line of the input file must be a JSON object of the form {"key": "...", "request": {...GenerateContentRequest...}}.

Returns the created batch operation object; use obj[:name] (e.g. "batches/123456") with get_batch_job, poll_batch_job, cancel_batch_job, and delete_batch_job.

Example

    BatchRequest("Tell me a one-sentence joke."; key="request-1"),
    BatchRequest("Why is the sky blue?"; key="request-2"),
])

GoogleGenAI.connect_live — Function
connect_live(provider, model; config=GenerateContentConfig(), functions=Dict{String,Function}(), setup_options...) -> LiveSession
connect_live(api_key, model; kwargs...) -> LiveSession
connect_live(model; kwargs...) -> LiveSession

Open a bidirectional streaming session with the Gemini Live API over a WebSocket (aio.live.connect() equivalent). Blocks until the server confirms with setupComplete, then returns a LiveSession.

Keyword arguments:

  • config::GenerateContentConfig: e.g. response_modalities=["AUDIO"] for voice output, plus speech_config, system_instruction, tools, thinking_config, temperature, ...
  • functions::Dict{String, <:Function}: executed automatically when the model issues a mid-session tool call.
  • input_audio_transcription::Bool=false: Transcribe the audio you send; transcripts arrive as :input_transcription on events.
  • output_audio_transcription::Bool=false: Transcribe the model's audio; transcripts arrive as :output_transcription on events.
  • session_resumption=nothing: true to make the session resumable, or a handle (from session.resumption_handle of an earlier session) to resume that session.
  • context_window_compression=nothing: true for sliding-window compression with default settings, or a dict such as Dict(:triggerTokens => 25_000, :slidingWindow => Dict(:targetTokens => 12_000)).
  • realtime_input_config=nothing: Voice activity detection and turn settings, e.g. Dict(:automaticActivityDetection => Dict(:disabled => true)) to signal activity yourself with send_realtime_input(session; activity_start=true).

Use send_realtime_input, send_client_content, recv_event, receive_text, and close_live!. See the README for full examples.
